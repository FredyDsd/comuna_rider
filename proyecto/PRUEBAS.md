# Criterios de Aprobación y Pruebas (Testing)

- **Prueba Fase 0:** El proyecto compila sin errores mostrando una pantalla en blanco y la conexión a Supabase está inicializada en código.
- **Prueba Fase 1:** La aplicación debe verse perfecta en vista de celular con los colores rojo y blanco predominantes[cite: 2]. La navegación entre pestañas no recarga la página.
- **Prueba Fase 2:** Un usuario debe poder registrarse y su perfil debe guardarse en la tabla de usuarios de Supabase con un rol base asignado.
- **Prueba Fase 3:** El usuario verificado debe poder tocar el mapa y agregar un "Pin de Control Policial"[cite: 2]. En Supabase, el registro del pin debe tener el ID del usuario.
- **Prueba Fase 4:** La calculadora debe arrojar el saldo neto en efectivo tras restar los gastos[cite: 2]. El tablón de turnos debe permitir borrar un turno publicado.
- **Prueba Fase 5:** El buscador del directorio debe filtrar correctamente si el usuario escribe "Gomería" o "Palpalá"[cite: 2].
